How it works

  1. Hold an Agent ID. The protocol checks balanceOf(your address) on the Agent ID contract — the official identity check. No Agent ID, no check-in.
  2. Check in once a day (UTC). Consecutive days grow your streak; a missed day restarts it at 1.
  3. Earn points. Each check-in awards 10 points plus a streak bonus of up to +20.
  4. Claim milestone badges at best streaks of 3, 7, 14 and 30 days. Badges are soulbound ERC-721 tokens with on-chain generated artwork.

Agent Streak is a free reputation game for Agent ID holders, running on BNB Chain. Points and badges are non-transferable records with no monetary value. Every transaction is signed by your own wallet — this site never asks for a seed phrase, private key or pairing code.
